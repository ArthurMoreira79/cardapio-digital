Cardápio digital de um restaurante fictício de **cozinha mineira**, com entradas, pratos principais, sobremesas e bebidas. Feito só com HTML e CSS, sem frameworks e sem JavaScript.

🔗 **Acesse:** [arthurmoreira79.github.io/Projeto-Restaurante](https://arthurmoreira79.github.io/Projeto-Restaurante/)

---

## O que tem na página

- **Topo** com a logo, o nome do restaurante e uma apresentação da proposta da casa.
- **Navegação fixa** com atalhos para cada seção do cardápio.
- **Quatro seções:** entradas, pratos principais, sobremesas e bebidas. Cada prato aparece num card com foto, nome, descrição, categoria e preço.
- **Layout responsivo**, com ajustes para notebook, tablet e celular.
- **Detalhes de acabamento:** animação de entrada nos cards, efeitos ao passar o mouse e tipografia com Cormorant Garamond, Playfair Display e Montserrat, carregadas pelo Google Fonts.

## Tecnologias e boas práticas

- HTML semântico (`header`, `nav`, `section`, `footer`) e atributos de acessibilidade, como `aria-label` na navegação e `aria-labelledby` em cada seção.
- CSS puro com Grid e Flexbox para o layout dos cards e media queries em três tamanhos de tela (1024px, 768px e 480px).
- Publicado com GitHub Pages.

## Estrutura

```
├── index.html    # página do cardápio
├── estilo.css    # estilos, animações e responsividade
└── imagens/      # fotos dos pratos, logo e favicon
```

## Como rodar localmente

Não precisa instalar nada: basta abrir o `index.html` no navegador.
